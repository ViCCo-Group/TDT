This is an (incomplete) list of dependencies if later new methods are introduced:
1. Some classification-related methods still allow only two labels. This 
   needs to be taken into account.
2. Feature selection and parameter selection use scaling. Scaling all data 
   can be dangerous, but at the moment it is assumed that training data 
   are balanced. When imbalances are allowed, this needs to be taken care 
   of.

It is not possible to combine external with prior dimensionality reduction.
Currently, there is a "bug" in that data is passed to the preparation of 
feature_selection, rather than current_data that should be passed. In that 
way, it also saves time, because data doesn't need to be selected again.
